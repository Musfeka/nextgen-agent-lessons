Agent Memory & Persistence

How do agents remember context across conversations and execution loops?

Time 15 minutes You will learn Short-term vs. Long-term memory and Vector DB integration

Without memory, an agent starts every conversation as a blank slate. Memory allows agents to maintain long-term context, learn from past mistakes, and track multi-step goals over time.

12.1 Types of Agent Memory

Type 1
Short-Term Memory

In-context memory maintained within the immediate window (e.g., chat history in the current session).

Type 2
Long-Term Memory

Persistent storage backed by Vector Databases or Key-Value stores (e.g., ChromaDB, Mem0) to retrieve past insights.
