Agentic RAG & Knowledge Retrieval

How do agents dynamically decide when and how to search external knowledge bases?

Time 20 minutes You will learn Query Rewriting, Self-Correction, and Tool-augmented RAG

Traditional RAG blindly retrieves documents for every user prompt. Agentic RAG gives the AI control to evaluate retrieved chunks, rewrite queries if necessary, and decide if external search is even required.

13.1 Traditional RAG vs. Agentic RAG

Traditional
Static Pipeline

User Prompt -> Vector Search -> Fixed LLM Generation (No reasoning about retrieval quality).

Agentic
Dynamic Reasoning Loop

User Prompt -> Agent Decides to Search -> Evaluates Quality -> Rewrites/Loops if needed -> Final Output.

13.2 Core Capabilities

  • Query Decomposition: Breaking a complex question into simpler sub-queries.
  • Relevance Grading: Filtering out irrelevant search results before passing them to the LLM context.
  • Fallback Actions: Deciding to use web search or code execution when local vector search fails.
